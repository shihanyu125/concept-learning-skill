# 类与对象

**一句话解释**：**类是图纸，对象是按这张图纸造出来的实物**——图纸只有一张，只规定「有哪些格子、会哪些动作」；实物可以造无数个，每个自己装自己的数据。

## 用一张表把两个词分清

| | 类 | 对象 |
| --- | --- | --- |
| 是什么 | `class 大学生:` 这一整段定义 | 用类造出来的那一个具体的人 |
| 有几个 | 只有一个 | 可以造任意多个 |
| 装什么 | 只规定有哪几项，不装具体值 | 每个对象各存各的值 |
| 会什么 | 定义好有哪些方法 | 每个对象都能用这些方法 |

「类」这个字本身的意思就是**归类**：把同一类东西的共性写一次，之后每个个体自动拥有这些能力，不用重复写。

## 三个必备零件

```python
class 大学生:
    def __init__(self, 姓名, 年龄, 学校="某大学"):
        self.姓名 = 姓名
        self.年龄 = 年龄
        self.学校 = 学校

    def 打招呼(self):
        print("你好，我是", self.姓名)
```

- **`class 名字:`** —— 画图纸，写下这个类有哪些数据和动作；
- **`__init__`** —— 初始化函数，**造对象时自动执行**，把传进来的参数装进对象里；
- **方法** —— 写在类里面的函数，只有这个类的对象才能调用。

## `self` 指谁

**谁在调用，`self` 就指谁。**

```
甲 = 大学生("甲", 20)
乙 = 大学生("乙", 21)
```

两次实例化各跑一次 `__init__`：第一次 `self` 是甲，第二次是乙。于是 `self.姓名 = 姓名` 这一行，写进的是**各自对象自己的格子**——同一个类，两套数据，互不干扰。

## 点语法：取数据与干活

- `对象.属性` → 取出这个对象身上存的值；
- `对象.方法()` → 让这个对象执行某个动作。

点是「的」的意思：`甲.打招呼()` 读作「甲的打招呼」，是它自己的动作，不是别人的。

## 一个新手必踩的顺序问题

**必须先把定义类的代码跑过，才能造对象。** 如果只写了 `class` 那一段却还没执行，就去实例化，程序会报「这个名字没有定义」——因为图纸还没画出来，自然造不出实物。

## 为什么值得学

类是把「数据」和「作用于数据的动作」**打包在一起**的手段。程序小的时候，用零散变量也能写；一旦对象多了，把每个人的姓名、年龄和它会做的动作各自归成一包，代码才不会乱。

## 生活类比

类像**一份表格模板**。

模板上印好了栏目（姓名、年龄、学校），但一个字都没填。你要办几个人的资料，就把模板复印几份，每份填不同的人。模板本身不是资料，它只规定「要填哪几栏」。
