# 模块与包

**一句话解释**：**一个 `.py` 文件就是一个模块**——把功能拆开写进不同文件，用的时候导入进来即可；这样零件可以到处复用，坏了一个换一个，不影响别的。

## 一个文件就是一个模块

写一个文件 `模块A.py`，里面有变量和函数；再写另一个文件，把前一个拿来用：

```python
import 模块A

模块A.打招呼()
```

运行第二个文件，就能调用第一个文件里的内容。文件与文件之间靠**导入**连起来。

## 两种导入写法

| 写法 | 调用时要写 | 什么时候用 |
| --- | --- | --- |
| `import 模块A` | `模块A.打招呼()` | 要用这个模块里的好几样东西 |
| `from 模块A import 打招呼` | 直接 `打招呼()` | 只反复用其中一样，少打几个字 |

两种写法功能上没有区别，差别只在于调用时要写多少前缀。

## 为什么要拆

把功能拆成模块，好处和**攒零件**一样：

- **可以复用**：一个模块写好了，很多地方都能调用；
- **便于替换**：某一块出问题，换掉那个文件就行，不必动全身；
- **便于阅读**：一个文件只管一件事，翻起来不累。

这也正是「模块」这个词的本义——**把一个整体按功能切开，每一块各管一段**。

## 包是模块的上一层

若干模块再按功能归到一起，就成了**包**。日常用的第三方库（比如 pandas）本身就是包：安装一次，里面几十上百个模块都能用。所以「装包」和「导入模块」是同一件事的两端——先装进来，再导进来。

## 生活类比

写程序像**总装车间加零件**。

`模块A.py` 是一个零件，主程序是总装线。零件可以装到不同的产品上；坏了一个零件，换掉它就行，不必把整台机器拆了。衣服和鞋袜也是同一个道理：做成一件件的，袜子破了换一双，不必整套重做。
