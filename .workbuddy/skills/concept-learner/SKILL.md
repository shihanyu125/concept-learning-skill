# concept-learner · 概念学习资料生成 Skill

## 一、适用场景

当你遇到一个**陌生的新概念**——课堂上的术语、论文里的名词、工作中的专业词——想真正把它弄懂，而不是只背一句定义时，用这个 Skill。

它会把一个空泛的概念，变成一份「带目标、带问题、带机制、带案例、带自测」的完整学习资料，让你从「知道这个词」走到「能用它思考和表达」。

## 二、输入信息

调用时你只需要提供：

| 字段       | 是否必填 | 说明       | 示例                        |
| -------- | ---- | -------- | ------------------------- |
| **概念名称** | 必填   | 要学习的概念   | `Agent`、`大模型的上下文`、`Skill` |
| **学习深度** | 选填   | 三档控制详略：入门 / 进阶 / 深入（默认入门） | `入门`、`进阶`、`深入`            |
| **你的背景** | 选填   | 用于调整解释深度 | 「非计算机专业」「会一点 Python」      |
| **特殊要求** | 选填   | 偏好的讲法    | 「多给生活化类比」「重点讲和 X 的区别」     |

## 三、生成步骤

按以下顺序，一步一步产出内容（不要跳步）：

> **先定深度**：根据输入的学习深度档位，决定内容的详略与术语密度——「入门」多用类比、少术语；「进阶」术语与机制并重；「深入」补充原理细节与边界讨论。

1. **定目标** —— 明确学完这个概念后，学习者「应该能做到什么」（学习目标）。
2. **提问题** —— 提出这个概念要回答的「核心问题」，引导带着问题去读。
3. **下定义** —— 用一句话大白话 + 一个生活类比，先讲清「它是什么」。
4. **拆机制** —— 拆解这个概念的核心组成 / 工作原理，说明它是「怎么运转的」。
5. **给场景** —— 至少一个具体、真实的应用场景，让人看到它「用在哪」。
6. **辨析边界** —— 指出它最容易和什么概念混淆，以及它的使用边界 / 局限。
7. **出自测** —— 出 3 个自测题，检验是否真的掌握（附答案）。
8. **查来源** —— 列出可核查的权威来源链接，供进一步阅读。

## 四、输出结构

生成的学习资料统一采用以下**九段式**结构（保存为 HTML 文件，便于在浏览器中阅读）：

1. **学习目标**（学完应能做到什么）
2. **核心问题**（这个概念要回答的关键问题）
3. **一句话解释**（个人化表述，不用教科书腔）
4. **核心机制 / 组成**（它是怎么工作的）
5. **一个具体应用场景**（真实、不空泛）
6. **容易混淆的点 / 使用边界**
7. **自测题**（3 题，含答案）
8. **可核查的资料来源**（带链接）
9. **我的理解与核查笔记**（由学习者本人填写，体现个人思考）

## 五、资料来源要求

- 来源必须是**真实存在、可点击访问**的权威资料（官方文档、知名技术博客、正规教材）。
- **禁止伪造链接**；不确定的来源先搜索核实再写。
- 优先官方文档，其次知名社区（知乎、掘金、官方博客等）。
- 每条来源注明它讲了什么，方便定位到具体章节。

## 六、自检要求（生成后必须逐条核对）

- [ ] 学习目标具体、可检验，不是空话
- [ ] 核心问题切中要害，能引导思考
- [ ] 概念解释准确，没有事实错误
- [ ] 至少有一个类比，能让非专业的人看懂
- [ ] 应用场景具体真实，不是空话套话
- [ ] 辨析部分确实指出了易混淆对象
- [ ] 自测题能检验理解，答案正确
- [ ] 来源链接真实可访问
- [ ] 学习者本人已阅读并填写「我的理解与核查笔记」

## 七、可复用性说明

本 Skill **不针对某一个具体概念**，而是定义了一套「学透任意概念」的通用流程。你下次遇到任何新概念，只要把概念名填进输入，就能复用同一套步骤生成新资料。它会随你学习的积累，持续沉淀成你的个人知识库。
